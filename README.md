Editora PISK - Sistema de Gestão
Este projeto é uma simulação de uma plataforma de gestão e catálogo para uma editora, desenvolvido como parte do currículo técnico do meu Ensino Médio. O sistema permite visualizar livros, organizar o acervo e simula uma empresa real.

Tecnologias Utilizadas:
Frontend: HTML5, CSS3 e JavaScript.
Framework Visual: Bootstrap (Design Responsivo).
Backend: PHP.
Banco de Dados: MySQL (gerenciado via WampServer).

Funcionalidades
Catálogo de Livros: Exibição dinâmica de títulos vindos do banco de dados.
Sistema de Conexão: Integração entre o servidor PHP e o MySQL.
Organização: Estrutura de pastas separada por componentes e estilos.

Como rodar o projeto localmente
Certifique-se de ter o WampServer instalado.
Clone este repositório na pasta C:/wamp64/www/...
Importe o banco de dados (se houver um arquivo .sql) no seu phpMyAdmin.
Configure as credenciais no arquivo conexao.php.
Acesse localhost/site-pisk no seu navegador.
